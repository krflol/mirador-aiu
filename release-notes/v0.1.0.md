Initial standalone Rust plugin for Mirador external-panel protocol v1.

- Claude and Codex account usage, active logins, recommendation badges, quota bars, locks, reset times, and cached-data notices.
- Keyboard account selection and confirmed switching through AIU's existing CLI.
- Asynchronous requests that keep Mirador responsive and let AIU finish credential operations after the panel closes.
- Bounded output and frames, generic diagnostics, and provider filtering.
- Synthetic demo mode with no AIU execution or credential access.

Requires Mirador 1.6.0 or a newer protocol-v1 host and a separately installed AIU Rust 0.2.0 or newer. Add the plugin command and layout placement from `examples/mirador.toml`; use `examples/demo.toml` for an account-free preview.

Archives include the native executable, README, MIT license, and example configurations. Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `SHA256SUMS` lists the archive hashes. Linux builds use Ubuntu 22.04 and need compatible glibc; macOS binaries are not notarized.

Credentials remain in AIU. The plugin does not add accounts, handle OAuth, read token files, or replace AIU's refresh and throttling policies. Closing Mirador allows an already-started AIU operation to finish rather than interrupting credential persistence.
